Pencarian teks Arab dengan normalisasi harakat cerdas. Anda dapat mengetikkan lafadz Arab gundul maupun berharakat untuk menemukan matan hadits secara akurat.

2. Akses dari Komputer Lain (Jaringan Lokal)
Secara bawaan server hanya menerima sambungan dari komputer ini. Aktifkan pilihan berikut bila vMix atau OBS berjalan di komputer lain dalam jaringan yang sama.
Perhatian: selama aktif, siapa pun di jaringan yang sama dapat mengubah tayangan tanpa izin. Aktifkan hanya selama siaran, lalu matikan kembali. Bila Windows Firewall bertanya, pilih Allow access untuk jaringan Private — jangan untuk jaringan publik.

3. vMix Title Editor — JSON Data Source
Webquran otomatis memperbarui berkas feed JSON lokal setiap Anda memilih atau menavigasi ayat:
Langkah Pemasangan di vMix:
  1. Buka Title Editor pada input Title vMix Anda.
  2. Klik Data Source → Manage → Tambahkan data source tipe "JSON".
  3. Paste path file di atas ke kolom Filename / URL.
  4. Petakan kolom teks: Arab, Terjemahan, dan Judul ke field teks title Anda.
🚦 Indikator vMix di Status Bar: 🟢 Berkedip Hijau = Feed JSON berhasil ditulis • 🔴 Berkedip Merah = Izin folder penyimpanan terhambat.
1

Persiapan Template & Output

Tentukan template yang sesuai dengan format acara Anda. Untuk salat berjamaah & proyektor masjid, gunakan template Default Fullscreen. Untuk siaran podcast kajian atau live streaming, gunakan template Lower Third Light atau Dark.

2

Memuat Ayat Secara Cepat

Gunakan Universal Omnibar (Ctrl+K) untuk langsung mengetik nama surat dan nomor ayat (misal: al-kahf 1). Teks Arab, latin, dan terjemahan akan langsung termuat tanpa perlu mencari satu per satu.

3

Navigasi Mengikuti Bacaan

Tekan tombol panah → untuk melangkah ke ayat berikutnya seirama dengan bacaan qari. Webquran secara cerdas akan otomatis berpindah ke surat berikutnya jika ayat terakhir surat telah selesai dibaca.

4

Blackout & Tally Siaran

Tekan Spasi kapan saja untuk melakukan Cut to Black (menyembunyikan tampilan layar tanpa mematikan koneksi). Indikator Tally di header akan berubah warna menjadi abu-abu HIDE, memberi kepastian status on-air 100%.

5

Keandalan 100% Offline Tanpa Buffer

Seluruh teks ayat Al-Qur'an 30 Juz dan database terjemahan tersimpan secara lokal di aplikasi laptop operator. Anda dapat mengoperasikan siaran di mana pun secara mulus tanpa bergantung pada sinyal internet.

Pemeriksaan Siaran (sebelum mulai)
Periksa hal-hal yang paling sering gagal di venue baru: font, server, layar, folder feed vMix, dan data hadits. Jalankan sebelum siaran dimulai, bukan saat sudah mengudara.
